# Shared data

`cleaned.csv` and `split_manifest.csv` are the `member-a-v1` data used by the code.

- Source: Md Saikot Hossain (2026), *Used Car Price Prediction Dataset*, V2, Mendeley Data, DOI `10.17632/8d38h82fyt.2`, CC BY 4.0.
- 5,997 listings; 4,789 development / 1,208 holdout; 5,608 attribute groups.
- SHA-256: see `../DATA.md`.
- Targets are asking prices in BDT, not transaction prices. Attribute groups are not verified vehicle IDs.
